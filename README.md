# SealMark 铃印 - 跨平台桌面水印工具

一款基于 C# 和 Avalonia 框架开发的跨平台桌面水印工具。支持单张图片添加水印，也支持批量加水印。程序运行速度快，本地处理，无网络访问，隐私安全有保障。

## 功能特性

- **单图加水印**：支持选择单张图片，自定义水印内容、字体、大小、颜色、透明度、位置等参数。
- **批量加水印**：支持一次性选择多张图片，快速批量添加水印，处理速度快。
- **跨平台支持**：基于 Avalonia UI 框架，可在 Windows、macOS、Linux 等主流操作系统上运行。
- **隐私安全**：所有图片处理均在本地完成，程序无任何网络访问，不上传任何数据，保护你的隐私。
- **轻量高效**：程序体积小，启动快，占用系统资源少。

## 技术栈

- **开发语言**：C# / .NET
- **UI 框架**：Avalonia UI

## 使用说明

1. 打开程序后，点击「添加图片」按钮，选择需要添加水印的图片（支持多选）。
2. 在右侧面板中设置水印参数，包括水印文字、字体大小、颜色、透明度、旋转角度、位置等。
3. 参数设置后水印效果即时展示。
4. 点击「保存全部」按钮，选择保存目录，即可导出和预览效果一致的图片。
5. 批量处理时，程序会自动处理添加的所有图片，导出效果和预览一致，快速完成水印添加。
